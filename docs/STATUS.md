# Статус

19.11.2026. Версия 1.0, репозиторий публичный.

Работает: очередь с перетаскиванием в окно и на Док, живой текст, txt, md, srt, vtt, json, экспорт,
история между запусками, каталог и загрузка моделей с проверкой SHA-256, переключение моделей,
словарь терминов, щадящий режим, предупреждения о зацикливании и обрыве, светлая и тёмная тема.
35 тестов, включая прогон настоящего whisper и скачивание с HuggingFace. Проверено на голосовых,
9-минутной записи (46 с на M4), беззвучном видео и загрузке модели через интерфейс.

Не проверено автоматически: перетаскивание мышью в окно (путь через Док и `open` проверен),
диалоги сохранения при экспорте, удаление модели через диалог.

Дальше, если понадобится: воспроизведение по таймкоду, уведомление о конце очереди, подписанная
сборка в Releases, чтобы ставить без Command Line Tools.
