# Статус

19.11.2026. Версия 1.0 установлена в `/Applications/Расшифровка.app`.

Работает: очередь с перетаскиванием в окно и на Док, живой текст, txt, md, srt, vtt, json,
экспорт, история между запусками, настройки, светлая и тёмная тема. 22 теста, включая сквозной на
настоящем whisper. Проверено на голосовых из Telegram, 9-минутной записи (46 с на M4) и беззвучном
видео.

Не проверено автоматически: перетаскивание мышью в окно (путь через Док и `open` проверен),
диалоги сохранения при экспорте.

Дальше, если понадобится: воспроизведение записи по клику на таймкод, уведомление о конце очереди,
разделение по говорящим.
