# Решения

## D-001. Нативное SwiftUI-приложение поверх whisper-cli

Решение: SwiftUI, Swift Package без Xcode-проекта, распознавание через установленный `whisper-cli`
из Homebrew, а не через встроенную библиотеку.
Почему: Док и «Открыть с помощью» работают только у настоящего .app; whisper.cpp из Homebrew уже
стоит и обновляется через brew; собирается одними Command Line Tools.
Отвергли: веб-интерфейс на localhost (нет приёма файлов на иконку, отдельный сервер в фоне),
MacWhisper (платный, удалён), сборку whisper.cpp внутрь приложения (своя сборка Metal и обновления).

## D-002. Аргументы whisper: VAD, -mc 0, подсказка с --carry-initial-prompt

Решение: `--vad` с silero, `-mc 0`, для ru, en и uk короткая подсказка с пунктуацией, повторяемая
в каждом 30-секундном окне.
Почему: без VAD whisper на тишине пишет титры вроде «Редактор субтитров…» (проверено на беззвучном
видео). `-mc 0` убирает зацикливание на длинных записях, но без контекста пропадает пунктуация;
подсказка в каждом окне её возвращает (проверено на голосовых 19.11.2026).
Отвергли: контекст по умолчанию (-mc -1): предложения чуть ровнее, но на длинных файлах риск
повторов.

## D-003. Один прогон, все форматы из JSON

Решение: whisper всегда пишет JSON, txt, md, srt, vtt и json приложение рендерит само.
Почему: можно выгрузить любой формат потом без повторного распознавания; один фильтр галлюцинаций
для всех форматов; субтитры режутся на реплики до 84 знаков.

## D-004. Сохранение рядом с исходником без перезаписи

Решение: по умолчанию `.txt` и `.md` в папку исходного файла, при совпадении имени `имя 2.txt`.
Если папка недоступна, файлы уходят в `~/Documents/Расшифровки`. Для записи без речи файлы не
создаются.

## D-005. Модели скачиваются из настроек, по умолчанию turbo

Решение: каталог многоязычных моделей whisper.cpp и детектора Silero во вкладке «Модели», загрузка
с HuggingFace в `~/.whisper` с докачкой после обрыва и проверкой размера и SHA-256 из API
HuggingFace; файл появляется в папке только после проверки. Пока пользователь сам не выбрал модель,
используется large-v3-turbo.
Почему: публичному приложению нужна установка без терминала. Схема проверки взята из скрипта
загрузки модели в учебном пайплайне лекций. Скачанная для сравнения large-v3 не должна молча
становиться основной: она в 3–4 раза медленнее.
Отвергли: англоязычные модели `.en` (не понимают русский), автоматическую загрузку при первом
запуске (1,6 ГБ без спроса).

## D-006. Словарь, щадящий режим и проверка качества

Решение: имена и термины из настроек добавляются к подсказке (до 400 знаков); щадящий режим
запускает whisper с `-t 2` и приоритетом utility; после распознавания предупреждение, если фраза
из трёх и более слов повторилась 10+ раз и это 15%+ сегментов, или если речь кончилась раньше
середины записи длиной от минуты.
Почему: все три приёма проверены на расшифровке лекций в учебном пайплайне: подсказка с
фамилиями и терминами по курсу, `nice 15` и два потока, чтобы не мешать работе, те же пороги
зацикливания и обрыва. Предупреждение просит послушать место, а не переделывает текст.
